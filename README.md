# Smartcar 智能车开源代码库

面向智能车协会「循迹杯」培训，收录五路红外循迹参考代码、硬件接线约定与实车调试清单。

[硬件清单与接线](hardware/README.md) · [上车调试](docs/bring-up.md) · [贡献指南](CONTRIBUTING.md)

| 内容 | 首版范围 |
| --- | --- |
| 参考车型 | STM32F103C6T6、TB6612FNG、红外传感器、4WD 底盘 |
| 控制示例 | 五路加权误差、PD 转向、输出限幅、丢线停车 |
| 验证状态 | 可在电脑上运行演示及自动测试。STM32 固件移植和实车验证待完成。 |

## 快速开始

用 Python 3.10 或更高版本在仓库根目录运行，无需安装第三方库。

```bash
python demo.py
python -m unittest discover -s tests -v
```

演示依次输入居中、偏左、偏右、丢线和恢复居中的传感器读数，输出左右轮指令。传感器按车头视角从左到右编号，数值越大表示越可能检测到黑线。输出范围为 0 至 1，0 表示停车。示例周期为 20 ms，参数用于桌面演示。
