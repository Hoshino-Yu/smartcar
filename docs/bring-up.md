# 实车调试

本页用于移植后的上车检查。桌面示例验证控制逻辑，实车记录须按板卡、固件提交和赛道条件填写。

1. **上电前检查**。核对供电、共地、SWD、传感器顺序和驱动使能。架空车轮后，用低占空比逐路确认左右轮和前进方向。
2. **传感器标定**。分别记录五路在黑线、背景上的读数，逐路确定阈值或归一化区间。黑线应产生较大的控制输入，确保无黑线时五路归零。
3. **控制移植**。在固定周期内采集传感器、计算误差并更新 PWM。上电保持停车，收到启动操作后再使能电机。全丢线立即输出零，清除微分历史。
4. **低速跑车**。先测直道与弯道，再主动移出黑线检查停车。记录板卡型号、固件提交、控制周期、参数、赛道和每项结果。

发现左右转向相反时，按顺序检查传感器排列、电机方向及 PWM 通道映射。
