# 参考车型硬件

| 部件 | 参考规格 | 接线前核对 |
| --- | --- | --- |
| 主控 | STM32F103C6T6 开发板 | 板卡版本、供电端口和 SWD 接口 |
| 驱动 | TB6612FNG 双路电机驱动模块 | 逻辑电源、电机电源、持续电流与电机负载 |
| 传感器 | 5 路红外反射传感器 | 输出是数字还是模拟，高电平电压和黑线极性 |
| 底盘 | 4WD 双层底盘 | 左右电机分组、电机额定电压和总电流 |

## 信号连接

| 信号 | 连接约定 |
| --- | --- |
| AIN1 / AIN2 / PWMA | 左轮方向与 PWM |
| BIN1 / BIN2 / PWMB | 右轮方向与 PWM |
| STBY | 主控使能。上电调试时保持禁用，方向和 PWM 初始化后再使能 |
| S0 至 S4 | 面向行进方向从左到右。数字输出接 GPIO，模拟输出接 ADC |
| VCC / VM / GND | VCC 接符合模块要求的逻辑电源，VM 接匹配电机的电源，主控、传感器和驱动共地 |

具体 STM32 引脚由实际板卡及其 CubeMX 工程确定。写入工程前先核对信号电平、PWM 通道及引脚复用。若同侧两台电机的合计负载超出单路驱动能力，需调整驱动配置。
